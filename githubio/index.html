Typst novel template

StoryTemplate

A minimal template for writing novels with Typst.

View on GitHub Read the README

Bootstrap a new novel repo

Creates a new folder + fresh Git repo, then stamps your metadata.

curl -fsSL https://raw.githubusercontent.com/anitasv/StoryTemplate/main/scripts/bootstrap.sh | bash

Then build a PDF:

cd YourProjectFolder
make pdf

What you get

  • Chapters in chapters/ (start with chapters/chapter1.typ)
  • Chapter ordering in story.typ
  • Print/PDF entrypoint in print.typ
  • Ebook/HTML entrypoint in ebook.typ
  • Build tooling via Makefile (outputs into output/)
  • EPUB metadata + CSS in styles/

Common build commands

make        # build all (PDF + HTML + EPUB)
make pdf    # print/PDF layout
make html   # ebook/HTML layout (source for EPUB)
make epub   # requires pandoc
make odt    # chapter .odt files (requires pandoc)
make wc     # word count across chapters
make clean

Prerequisites

You’ll need Typst (required) and Pandoc (required for EPUB/ODT). On macOS, the bootstrap script can optionally install missing prerequisites via Homebrew.
